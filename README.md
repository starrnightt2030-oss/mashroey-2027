# مشروع التخرج

تطبيق ويب (PWA) يتثبت على الموبايل: المدرس يرفع ملفات PDF، والطالب يقرأها ويعلّم عليها ويكتب ملاحظاته — حتى من غير نت.

**رابط التطبيق:** https://starrnightt2030-oss.github.io/mashroey-2027/

## المميزات
- عرض ملفات PDF بنفس شكلها الأصلي (PDF.js) — العربي والتشكيل بيفضلوا سليمين.
- قلم ناعم بيحس بالضغط، قلم تحديد، ملاحظات مكتوبة على الصفحة، ممحاة، تراجع/إعادة.
- علامات مرجعية بأسماء وألوان، و«كمّل من مكان ما وقفت».
- دفتر ملاحظات لكل ملف: ملاحظات مكتوبة، كتابة بخط اليد، وأسئلة مهمة كبطاقات بتتقلب.
- قراءة صوتية عربية، أو تسجيل صوتي من المدرس.
- تصدير الملف بتعليقات الطالب، ونسخة احتياطية للملاحظات.
- وضع داكن، ووضع ليلي للصفحات، وتكبير بصباعين.
- لوحة مدرس بكلمة سر: رفع الملفات ومزامنتها مع المستودع ده في خطوة واحدة.

## هيكل الملفات
- `files/index.json` — قائمة الملفات (بتتحدث تلقائي من لوحة المدرس).
- `files/*.pdf`، `files/thumbs/`، `files/audio/` — الملفات المرفوعة.
- `js/` — كود التطبيق، `vendor/` — المكتبات (شغالة أوفلاين).
